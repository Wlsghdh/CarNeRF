```
딜러도 감정사도 매장 방문도 필요 없습니다 — AI가 영상 한 번으로 중고차 거래의 모든 판단을 대신합니다 (90자)
```

**대안 후보**:

A) 도전적 톤 (61자):
```
중고차 거래에서 사람을 AI로 완전 대체합니다 — 영상 한 번이면 3D 모델·결함 진단·시세까지 자동
```

B) 절제된 톤, 키워드 강조 (75자):
```
매매상 없이, 감정사 없이 — AI 하나로 끝내는 중고차 거래. 3D 재구성·결함 탐지·시세 산정 모두 자동화
```

C) 명사형 슬로건 (58자):
```
중고차의 모든 판단을 AI가. 스마트폰 영상 한 번에 3D 모델·결함 진단·적정가 산출까지 끝
```

D) 가장 강한 직접 도전 (88자):
```
"믿을 수 있는 중고차"는 사람이 만들지 않습니다. 영상 한 번이면 AI가 3D 모델·결함·시세를 모두 책임지는 거래 플랫폼
```

## Q2. 아이디어 배경 이야기 (필수, 1~1000자)

**답변** (약 870자):

```
Computer Vision 분야의 논문을 즐겨 읽던 중, 우연히 NeRF(Neural Radiance Fields)
라는 연구를 접하게 되었습니다. 여러 장의 사진만 있으면 촬영되지 않은 각도의
장면까지 사실적으로 예측해서 보여줄 수 있다는 점에 큰 충격을 받았습니다.

마침 미국의 한 부동산 앱에서 NeRF 기술을 적용해, 사용자가 집을 직접 방문하지
않고도 모든 방을 자유롭게 둘러볼 수 있게 한 사례를 보았습니다. "가서 봐야만
믿을 수 있다"는 그 시장의 한계를 NeRF가 깨고 있는 모습을 보면서, 한국에서도
이 기술이 가장 강력하게 작동할 수 있는 시장이 어디일까 고민하기 시작했습니다.

여러 분야를 검토한 끝에 자연스럽게 중고차 시장이 떠올랐습니다. 거래 금액이
크고, 직접 보지 않으면 신뢰하기 어렵고, 외관의 작은 결함이 가격에 직결되는 —
부동산과 거의 동일한 구조의 시장이었기 때문입니다. 다만 단순히 3D로 보여주는
것만으로는 부족했습니다. 진짜 신뢰는 결국 가격, 상태, 안전 거래까지 모두
객관적으로 보장될 때 만들어진다는 것을 깨달았습니다.

그래서 다섯 가지 기능을 한 플랫폼에 통합하기로 했습니다.

- 3D 모델링: NeRF 후속인 3D Gaussian Splatting으로 영상 한 번이면 차량의
  모든 면을 사실적으로 재구성
- AI 파손 진단: YOLOv8 기반 모델로 스크래치, 덴트, 도색 손상을 자동 탐지
- AI 가격 예측: 5만 건 이상의 실거래 데이터를 학습한 LightGBM으로 적정 시세 산출
- AI 차량 요약: 차량 도메인 전용 RAG로 차량의 상태와 이력을 한눈에 정리
- 에스크로 결제: 거래 전 과정의 안전을 보장하는 안심 결제

이 다섯 가지가 한 플랫폼에 모일 때 비로소 "가서 직접 보지 않고도 믿을 수
있는 중고차 거래"가 완성된다는 결론에 도달했고, 그렇게 CarNeRF를 시작하게
되었습니다.
```

**사진 추천 (선택)**:
- NeRF 부동산 사례 캡처 (검색해서 첨부) — 영감이 된 사례 시각화
- `promo_assets/01_raw_videos/cut3_3d_split.mp4` 한 프레임 (촬영→3D 비교)

## Q3. 누구의 어떤 문제를 해결하나요? (필수, 1~1000자)

**답변** (약 940자):

```
중고차 시장에서 가장 큰 어려움을 겪는 사람은 차량에 대한 정보가 부족한 일반
구매자입니다. 20~40대 첫차 또는 세컨드카 수요자들은 보통 사진 몇 장과 짧은
설명만으로 수백만에서 수천만 원에 이르는 거래를 결정해야 합니다. 그러나
사진으로는 외관의 미세한 스크래치나 덴트, 도색 흔적을 알 수 없고, 매물을
직접 보러 가더라도 짧은 시간 안에 판단을 내려야 하는 압박이 따릅니다.
매매상이 제시하는 시세를 신뢰하기는 어렵지만 본인이 적정가를 산정할
객관적 도구는 없고, 사고이력 조회 서비스가 있어도 결함을 시각적으로 확인할
방법은 없습니다. 결국 많은 구매자가 "직접 가서 봐야만 안심"이라는 비효율로
돌아가게 되거나, 아예 중고차 구매 자체를 포기합니다.

판매자도 다른 종류의 문제를 안고 있습니다. 개인 셀러와 중소형 매매상은
차량 상태를 객관적으로 입증할 방법이 없어 가격 협상에서 항상 불리합니다.
직접 거래는 시간과 노력이 너무 많이 들고, 큰 매매상에 위탁하면 마진을
빼앗깁니다. 사진을 잘 찍는 것조차 별도의 일이지만, 잘 찍는다고 해서 신뢰가
자동으로 형성되지도 않습니다.

CarNeRF는 양측의 문제를 단 하나의 영상으로 동시에 해결합니다. 구매자는
집에 앉아서도 매물을 360도로 실측하듯 살펴보고, AI가 객관적으로 분석한
결함 리포트와 적정 시세를 받아본 뒤 에스크로 결제로 안전하게 거래를
마무리할 수 있습니다. 판매자는 별도의 인증 절차 없이도 차량 상태가
객관적으로 검증되어 신뢰 기반의 가격을 당당하게 제시할 수 있고, 비대면
으로 훨씬 넓은 고객에게 노출됩니다. 특히 "혼자 매매상에 가기 두려운
여성과 노년층", "차에 대해 잘 모르는 첫차 구매자", "직접 보러 갈 시간이
없는 직장인" 같은 기존 시장의 정보 약자들에게 가장 큰 가치가 돌아간다고
보고 있습니다.
```

**사진 추천 (선택)**:
- `promo_assets/01_raw_videos/cut5_defect_yolo.mp4` 한 프레임 (AI 결함 탐지 화면)

## Q4. 어떻게 실현하실 건가요? (필수, 1~1000자)

**답변** (약 970자):

```
실현은 이미 시작되어 있습니다. 영상 한 번이면 차량을 3D로 재구성하는 3D
Gaussian Splatting, 외관 결함을 자동 탐지하는 YOLOv8, 5만 건의 실거래
데이터로 학습한 LightGBM 시세 예측 모델, 그리고 차량 도메인에 특화된
전용 RAG 기반 차량 요약 LLM을 직접 구현해 FastAPI 백엔드에 통합한 MVP를
이미 가지고 있습니다. NF소나타와 기아 모닝 같은 실제 차량으로 학습부터
웹 배포까지 검증을 마쳤고, 사이트에 접속하면 누구든 즉시 3D로 차량을
둘러보고 AI 진단 결과를 확인할 수 있습니다. 즉, 기술적 실현 가능성은
이미 증명된 상태에서 출발합니다.

여기서부터 사업으로 키워가는 방식은 단계별로 위험을 작게 쪼개는 전략을
택했습니다. 우선 첫 6개월은 수도권 개인 매물 1,000건을 무료 등록으로
확보하고 거래가 성사될 때마다 에스크로 수수료 1%만 받는 가벼운 B2C
베타로 시작해 시장의 반응(PMF)부터 검증합니다. 매매상에 가기 두려운
여성·노년층, 차에 대해 잘 모르는 첫차 구매자처럼 기존 시장이 가장 잘
대해주지 않았던 정보 약자층을 우선 타겟해 초기 신뢰를 확보하는 방식입니다.
PMF가 확인되는 6개월부터 18개월 사이에는 검증된 기술을 B2B로 확장합니다.
중소 매매상을 위한 매물 자동 등록·검수 SaaS를 월 구독으로 제공하고, 보험사
손해사정 업무용 사고차량 결함 진단 API를 별도로 공급해 매출 구조를
다각화합니다. 18개월 이후에는 그동안 누적된 5만 건 이상의 3D 모델과 결함
라벨 데이터를 자동차 OEM의 품질 검사 자동화, 자율주행 학습용 데이터셋
으로 자산화하고, 한국 중고차 수출의 거점인 동남아 시장으로 진출하는 것이
최종 목표입니다.

현재 운영은 수원대학교의 A100 80GB GPU 인프라와 풀스택·AI 협업 팀으로
충분히 굴러가고 있지만, 투자 유치 시 모바일 앱(iOS/Android) 출시, GPU 학습
큐 분산 처리, 매물 확보 마케팅에 우선 투입해 위 로드맵을 한 단계씩 단단히
실현해 나가는 것이 저희의 방향입니다.
```
