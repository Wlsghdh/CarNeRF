# 1. 문제인식 — 화성시의 구조적 문제

## 화성시, 어떤 도시인가?

화성시는 2025년 1월 경기도 5번째 특례시가 된 **인구 100만 대도시**입니다. 2001년 시 승격 당시 21만명이었던 인구가 23년 만에 5배로 폭증했고, **전국 인구 증가율 1위**를 기록하고 있습니다.

| 지표 | 화성시 | 비교 |
|------|--------|------|
| **면적** | 약 700 km² | 서울(605 km²)의 **1.16배** |
| **인구** | 약 100만명 (2025) | 전국 기초자치단체 4위 |
| **평균 연령** | 39.3세 | 전국 최연소 도시 중 하나 |
| **출생아 수** | 전국 1위 | 30~40대 젊은 가족 대규모 유입 |

그리고 이 도시에는 **삼성전자 화성캠퍼스(삼성 나노시티)**를 필두로 10곳 이상의 산업단지가 넓게 분포되어 있습니다.

| 주요 산업단지 | 특성 |
|---------------|------|
| 삼성전자 화성캠퍼스 | 반도체 생산 핵심 거점 |
| 동탄도시첨단산업단지 | IT/반도체 |
| 향남제약산업단지 | 제약 |
| 발안일반산업단지 | 제조업 |
| 화성바이오밸리 | 바이오 |
| 마도, 전곡, 주곡, 정남, 송산 등 | 다양한 중소기업 |

삼성전자를 비롯한 대기업과 수많은 중소기업 종사자들이 화성시에 거주하면서 출퇴근합니다. 그런데 문제가 있습니다.

---

## 문제 1: 자가용이 "선택"이 아니라 "필수"인 도시

화성시는 서울보다 넓은 면적에 **동탄, 봉담, 남양, 향남** 등 생활권이 완전히 분리되어 있습니다. 동부(동탄)에서 서부(남양)까지 대중교통으로 **2시간 이상** 걸립니다.

```
┌─────────────────────────────────────────────────────┐
│                    화성시 (~700km²)                   │
│                                                       │
│   [봉담]──────[동탄1·2]  ← 삼성전자, IT산업단지       │
│     │              │                                  │
│   [남양]──────[향남]     ← 제약/바이오/제조업           │
│   (시청)        │                                     │
│   [송산·서신]  [발안·마도] ← 해안 산업권               │
│                                                       │
│  ※ 각 생활권 간 대중교통 연결 극히 열악                │
└─────────────────────────────────────────────────────┘
```

이것이 숫자로 확인됩니다:

| 지표 | 화성시 | 비교 |
|------|--------|------|
| **버스 교통분담률** | **12.3%** | 경기도 평균 14.4%, 수원 15%, 성남 17% |
| **택시 1대당 인구** | **740~752명** | 전국 평균 309명 (2.4배 열악) |
| **자가용 분담률** | **약 80% 이상** (추정) | 버스+택시 13.4%를 제외한 나머지 |

언론에서는 화성시를 **"100만 교통지옥"**이라 부릅니다 (오마이뉴스, 2024). 산업단지가 넓게 분산되어 있고, 자취방이나 신도시에서 회사까지의 대중교통이 사실상 없거나 극히 불편합니다. 결국 **출퇴근을 위해 자가용이 필수**이고, 특히 사회 초년생과 젊은 직장인에게 **중고차가 가장 현실적인 첫 차 선택지**가 됩니다.

---

## 문제 2: 100만 도시인데 중고차 인프라가 없다

그런데 막상 화성시에서 중고차를 사려고 하면, **갈 곳이 없습니다.**

바로 옆 **수원시**에는 전국 최대 규모의 중고차 매매단지가 있습니다:

| | 수원시 | 화성시 |
|---|--------|--------|
| **대형 매매단지** | 도이치 오토월드 (1만대+), 수원중앙매매단지 등 **6곳 이상** | **없음** |
| **월 거래량** | 약 2만대 | 자체 거래 인프라 부재 |
| **등록 딜러** | 3,400명+ 최근 유입 | 소수 개인 딜러만 산재 |

화성시민이 중고차를 직접 보고 사려면 **수원까지 나가야** 합니다. 동탄에서 수원 매매단지까지는 그나마 30분이지만, 향남이나 남양에서는 1시간 이상 걸립니다. 결국:

- **딜러에 대한 의존도가 극도로 높아집니다** — 직접 가서 비교할 수 없으니 딜러 말만 믿어야 합니다
- **딜러 수수료를 그대로 감수해야 합니다** — 선택지가 없으니까요
- **온라인으로 사려고 해도 검증 수단이 없습니다** — 사진 몇 장으로 수백만원짜리를 결정해야 합니다

---

## 문제 3: 같은 화성시인데 시세가 다르다

화성시는 수원시와 달리 **동탄, 남양, 향남** 등으로 생활권이 뚜렷하게 나뉘어져 있습니다. 각 권역의 소득 수준, 산업 구조, 인구 밀도가 다르기 때문에 **같은 차종이라도 지역별로 중고차 시세가 다르게 형성**됩니다.

- **동탄**: 삼성전자 종사자 중심, 높은 구매력 → 시세가 상대적으로 높음
- **향남/발안**: 제조업 중심, 중저가 차량 수요 → 시세가 상대적으로 낮음
- **남양/송산**: 시청 소재지 + 해안권, 혼재

그런데 이 지역별 시세 차이를 객관적으로 보여주는 서비스가 없습니다. 엔카나 KB차차차의 시세표는 전국 또는 광역시/도 단위이지, **화성시 내 권역별 시세**까지는 반영하지 않습니다. 결국 화성시민은 "내 동네에서 이 차가 얼마인지" 알 수 없는 상태에서 거래합니다.

## 문제 정리: 화성시만의 구조적 악순환

```
 넓은 면적 + 분산된 산업단지 + 열악한 대중교통
              │
              ▼
      자가용 필수 (분담률 80%+)
              │
              ▼
      중고차 수요 극대화 (특히 20-30대)
              │
              ▼
    ┌─────────┴─────────┐
    │                   │
 매매단지 없음      딜러 부족
    │                   │
    ▼                   ▼
 수원까지 이동 필요   딜러 의존도 ↑
 (1시간+)           수수료 감수
    │                   │
    └─────────┬─────────┘
              │
              ▼
    비대면 거래 필요하지만
    검증 수단이 전혀 없음
              │
              ▼
   "비싸게 사거나, 불안하게 사거나"
    → 화성시 중고차 거래의 현실
```

이건 단순히 "중고차 시장의 일반적인 문제"가 아닙니다. **화성시의 지리적·교통적·인프라적 특수성이 만들어낸 지역 고유의 문제**입니다.

# 2. 해결책 — CarNeRF

## 화성시민을 위한 AI 중고차 플랫폼

저희 CarNeRF는 이 문제를 **기술로 해결**합니다.

핵심 아이디어는 단순합니다: **수원까지 안 가도, 딜러 없이도, 화성시에서 안심하고 중고차를 거래할 수 있게 만든다.**

| 화성시의 문제 | CarNeRF의 해결 |
|---------------|----------------|
| 매매단지까지 1시간+ | **3D 모델로 비대면 차량 확인** — 수원까지 갈 필요 없음 |
| 딜러 의존 → 수수료 부담 | **거래 수수료 0%** — AI가 딜러 역할 대체 |
| 차량 상태 검증 불가 | **AI 결함 자동 탐지** — 스크래치, 덴트, 도색 변색 감지 |
| 지역별 시세 차이 판단 불가 | **AI 가격 진단** — 화성시 권역별 시세 반영 |
| 전문 지식 부족 (20-30대) | **AI 차량 요약** — 장단점을 쉬운 말로 설명 |

```
판매자: 스마트폰으로 차량 촬영 (1~2분)
    │
    ▼
① 영상 → 프레임 추출 (2fps)
② COLMAP 3D 카메라 위치 추정
③ 3D Gaussian Splatting → 포토리얼리스틱 3D 모델
④ AI 결함 탐지 (YOLOv8) → 스크래치/덴트/변색 자동 감지
⑤ AI 가격 진단 (LightGBM) → 화성시 권역별 적정 시세 산출
⑥ ChatGPT 차량 분석 → 장단점/고질병 쉬운 말로 요약
    │
    ▼
구매자: 웹에서 3D 뷰어 + AI 진단 결과 확인
→ 수원까지 가지 않아도, 딜러 없이도 안심 거래
```

한 줄로 요약하면, **"당근마켓의 가격에 엔카의 신뢰성을, AI 기술로 실현하는 것"**. 그리고 이걸 **화성시에 특화**해서 시작합니다.

# 3. 실현가능성

## 이미 동작하는 프로토타입

이건 구상만 한 게 아닙니다. **실제로 동작하는 풀스택 프로토타입을 완성했습니다.**

| 항목 | 상태 |
|------|------|
| 3D Gaussian Splatting 파이프라인 | 완료 (표준 45분, HQ 140분) |
| 웹 3D 뷰어 + 결함 마커 | 완료 |
| AI 결함탐지 / 가격예측 / 차량요약 API | 완료 |
| 포인트 충전/사용 + 후기 시스템 | 완료 |
| 풀스택 웹 서비스 (FastAPI + Tailwind CSS) | 완료 |

### 기술 스택

| 분류 | 기술 |
|------|------|
| 3D 파이프라인 | PyTorch, CUDA 12.2, pycolmap, 3D Gaussian Splatting |
| AI 모델 | YOLOv8, SAM, LightGBM, scikit-learn |
| AI 분석 | OpenAI ChatGPT API (gpt-4o-mini) |
| Backend | FastAPI, SQLAlchemy, Python 3.11 |
| Frontend | Jinja2 SSR, Tailwind CSS, Three.js |
| 인프라 | NVIDIA A100 80GB x2 |

### 핵심 기술 설명

**1) 3D Gaussian Splatting — 사진이 아니라 3D로 본다**

판매자가 스마트폰으로 차량을 한 바퀴 촬영하면, COLMAP으로 카메라 위치를 추정하고, 3D Gaussian Splatting으로 포토리얼리스틱한 3D 모델을 자동 생성합니다. 구매자는 웹에서 차량을 360도 자유롭게 돌려보며 확인할 수 있습니다.

**2) AI 결함 탐지 — 눈으로 놓치는 것도 AI는 잡는다**

3D 모델을 여러 각도에서 렌더링한 뒤, YOLOv8 기반 AI가 스크래치, 덴트, 도색 변색 등을 자동 감지합니다. 결함은 3D 뷰어 위에 마커로 표시됩니다.

**3) AI 가격 진단 — "이 가격이 맞나?"에 대한 답**

동일 모델의 거래 기록, 연식, 주행거리, 결함 상태를 종합 분석하여 적정 가격을 산출합니다. 화성시 권역(동탄/향남/남양 등)별 시세 차이까지 반영합니다.

**4) AI 차량 요약 — 전문 지식 없이도 이해 가능**

ChatGPT API를 활용해 장단점, 고질병, 실사용자 후기를 종합하여 누구나 이해할 수 있는 말로 요약합니다.

# 4. 성장전략

## 시장 규모: 화성시 → 전국

### 화성시 타겟 시장 (SOM)

| 지표 | 수치 | 근거 |
|------|------|------|
| 화성시 인구 | 100만명 | 2025년 기준, 전국 4위 |
| 추정 자동차 등록대수 | 40~50만대 | 인구 대비 전국 평균 이상 (자가용 필수 도시) |
| 20-30대 비중 | 높음 | 평균연령 39.3세, 전국 최연소급 |
| 연간 중고차 거래 추정 | 수만 대 | 자가용 의존도 80%+ × 젊은 인구 |

화성시 20-30대 중고차 직거래 시장만으로도 **수백억원 규모**의 초기 시장이 됩니다.

### 확장 로드맵

```
Phase 1: 화성시 (2026)
  → 동탄/향남/남양 권역별 특화
  → 삼성전자·산업단지 종사자 타겟

Phase 2: 수원·오산·평택 (2027 상반기)
  → 인접 도시 확장
  → 경기 남부권 커버

Phase 3: 수도권 전역 (2027 하반기)
  → 전국 온라인 중고차 시장 진입
  → TAM 30~44조원, SAM 5조원+
```

### 전국 시장 규모 (참고)

| 구분 | 규모 | 출처 |
|------|------|------|
| **TAM** — 국내 중고차 시장 전체 | 30~44조원 | Frost & Sullivan, Mordor Intelligence |
| **SAM** — 온라인 중고차 시장 | 약 5조원 (2024) | 통계청 온라인쇼핑동향, 한국경제 |
| **SOM** — 20-30대 온라인 직거래 | 수천억원 | 온라인 시장의 30% × 직거래 비중 |

온라인 중고차 시장은 2020년 2.1조 → 2024년 5조+로 **4년 만에 2.4배 성장**, 지금도 연 40%+ 성장 중입니다.

## 수익 모델

거래 자체는 **수수료 0%**. 수익은 AI 부가서비스에서 만듭니다.
